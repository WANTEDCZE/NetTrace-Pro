# NetTrace Pro

Desktopová aplikace pro diagnostiku síťového připojení.

## Funkce

- ICMP ping monitoring
- TCP connect monitoring
- Porovnání ICMP a TCP odezvy
- Traceroute a historie jednotlivých hopů
- Heatmapa ztrát a diagnostika trasy
- Historické grafy a statistiky
- Export CSV kompatibilní s českým Excelem
- Export diagnostického PDF
- Ookla Speedtest CLI

## Požadavky

- Python 3.10+
- PySide6
- Systémový příkaz ping
- Traceroute (Linux/macOS; na Windows tracert)
- Oficiální Ookla Speedtest CLI pro test rychlosti
